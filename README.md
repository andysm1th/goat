Animated goat in pure text with Pretext.

- [Live demo](https://red-dream-cc3c.dflkjgldkfjgjdf.workers.dev/)
- [Embed it](https://red-dream-cc3c.dflkjgldkfjgjdf.workers.dev/embed)

```sh
pnpm install
pnpm dev          # demo at /, embed example at /embed.html
pnpm test
pnpm build        # the demo site, to dist/
pnpm build:lib    # the embeddable player, to lib/
pnpm preview
```
